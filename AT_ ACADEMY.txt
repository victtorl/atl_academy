CONCEPTOS DE POO:::::::

INTERFAZ::Es una Clase que DEFINE como se debe comportar una clase pero NO SE IMPLEMENTA
-Los atributos definidos en una Interfaz seimpre son publicos estaticos y finales
-Una clase puede implementar varias interfaces--
-Logica de implementacion: "puede hacer"  CAPACIDAD
 uso::Si colo quieres que cumplan con una misma regla o comportamiento usa interfaz


CLASE ABSTRACTA::No se  pueden instanciar directamente sirve como molde para que se implementen por clases hijas
-Herencia obligatoria, todos los metodos deben ser implementados,menos los implementrados 
-Puede tener metodos Normales ose implementados
-Una clase hija solo hereda una clase abstracta--
-Logica de implementacion: "ES UN" IDENTIDAD
 uso:: Se debe usar cuando quieres crear una plantilla base de un grupo de clases estrechamente relacionadas 
 uso:: Cuando tienes una clase generica que necesita ser instanciada 
 uso:: Cuando tines clases que compartenn mucho codigo interno use [clase abstracta]
Ejemplo: Vehiculo sera la calse abstracta pues se tiene para instanciar moto carro motocar


HERENCIA::Es un mecanismo en el cual un clase recibe caracteristicas de otra 

POLIMORFISMO::Es la capacidade de como  objetos diferentes [instancias de clases] responden
de manera diferente ante un metodo de otra clase
-Aveces hay sobreescritura de metodos con @override(dinamico) por eso exixsten dos clases de polimorfismo
-Hay [redefinicion del comportamiento] de la clase padre
Ejemplo: Hay una clase Animal que tiene metodo hacerSonido, 2 clases Perro, Gato 
usan el metodo hacerSonido pero uno dice "miau" el otro "guau"


polimorfismo estático::
-No usa @override
-Utiliza la sobrecarga de metodos [Overlading] (se implementan metodos con diferentes parametros)
-Overloading solo se usa para contructores y metodos
-Varios metodos con el  mismo nombre pero con diferentes parámetros
-Me da flexibilidad para realizar la misma accion logica con diferentes tipos de datos

polimorfismo dinamico::
-Usa @override
-Cuando se implementa una interfaz
-Cuando la descicion de que metodo ejecutar cambia mientras el progrma se esta ejecutando


CONSTRUCTORES::El constructor tiene el mismo nombre que la clase
-En el polimorfismos estatico se usan varios constructores con diferentes parametros


FIRMA DEL METODO:: Este concepto significa que la clase que implementa un metodo debe tener todos los parametros
debe ser identico tanto en nombre como en parametros






*********************REGLAS JAVA*****************
 -Si la clase padre tiene un constructor con parametros (y no tiene uno vacio)
  entonces la clase hija esta obligada a crear su propio contrcutor
